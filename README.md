## 快速开始

### 方式一：直接打开

双击 `index.html` 即可在浏览器中游玩。

### 方式二：本地服务器（推荐）

某些浏览器对本地文件的音频加载有限制，建议使用本地服务器：

```bash
# 使用 Python 3
python -m http.server 8000

# 或使用 Node.js
npx serve .

# 或使用 VS Code Live Server 插件
```

然后访问 `http://localhost:8000` 即可开始游戏。

## 游戏特色

- **六大门派**：少林、武当、丐帮、华山、全真、桃花岛，各有独特属性加成与专属武学
- **闪避与暴击系统**：闪避率决定躲避敌人攻击的概率，暴击率决定攻击翻倍的概率
- **实时时间系统**：游戏时间按照现实 10 分钟 = 1 天的速度流逝（金元纪年）
- **回合制战斗**：攻击、使用武学、使用物品、逃跑，策略由你决定
- **购物系统**：11 种商品，支持 +/- 数量选择，限购珍稀物品
- **批量使用物品**：战斗和非战斗中均可选择使用物品数量
- **随机事件**：宝箱、陷阱、奇遇、高人指点、偶遇陆小凤……江湖处处有惊喜
- **角色简历面板**：头像 + 属性一览，像简历一样直观
- **音频系统**：音效与背景音乐独立控制，支持自定义 MP3 选曲
- **自动存档**：使用 localStorage 保存，关闭浏览器也不会丢失进度

## 战斗系统

### 敌人列表

| 敌人     | 气血 | 攻击 | 防御 | 银两 | 经验 |
| -------- | ---- | ---- | ---- | ---- | ---- |
| 山贼     | 60   | 8    | 2    | 30   | 20   |
| 盗匪     | 80   | 11   | 3    | 50   | 35   |
| 黑衣人   | 110  | 14   | 4    | 80   | 55   |
| 赏金杀手 | 140  | 17   | 5    | 120  | 80   |
| 武林盟主 | 200  | 22   | 8    | 200  | 150  |

### 战斗操作

- **普通攻击**：对敌人造成基础伤害
- **使用武学**：消耗内力施展门派武学，造成更高伤害
- **使用物品**：从背包中选择物品，支持 +/- 选择使用数量
- **逃跑**：有一定概率脱离战斗

### 比武招亲

- 等级 ≥ 2 方可参加
- 胜率公式：`15% + (等级-2) × 6% + 攻击 × 0.3%`
- 胜利奖励：50 + 等级 × 20 银两
- 失败损失：20 银两报名费

### 伤害公式

```
普通攻击伤害 = max(1, 攻击 - 防御) + 随机波动(0~4)
武学伤害 = max(1, 武学伤害 + 攻击 - 防御)
暴击伤害 = ⌊原伤害 × 2⌋（概率触发，基础5%）
闪避机制：敌方攻击有概率被完全闪避（基础5%）
```

**暴击规则**：玩家攻击时有 `暴击率%` 概率触发暴击，伤害翻倍。
**闪避规则**：敌人攻击时有 `闪避率%` 概率被完全躲开，不造成任何伤害。

**闪避与暴击的成长**：
- 基础闪避/暴击：各 5%
- 每升一级：闪避 +0.5%，暴击 +0.5%
- 门派加成：不同门派提供额外的闪避/暴击加成
- 永久道具：可在杂货铺购买「轻身步法」「暴击秘籍」永久提升

## 时间系统

游戏采用 **金元纪年**，时间流速为现实的 **144 倍**（现实 10 分钟 = 游戏 1 天）。

| 现实时间 | 游戏时间       |
| -------- | -------------- |
| 10 分钟  | 1 天           |
| 5 小时   | 1 月（30 天）  |
| 60 小时  | 1 年（360 天） |

### 限制规则

- **武馆修炼**：每游戏月限一次（通过 `年×12 + 月` 判断）
- 创建角色时起始日期随机（1~12 月，1~30 日）

### 显示格式

```
金元1年6月15日
```

## 随机事件

在郊外荒野"继续深入"时触发，概率分布如下：

| 事件       | 概率 | 说明                                          |
| ---------- | ---- | --------------------------------------------- |
| 遭遇战斗   | 50%  | 随机敌人进入战斗                              |
| 发现宝箱   | 15%  | 获得 20~60 银两                               |
| 遇到陷阱   | 10%  | 损失 8~20 点气血                              |
| 江湖高人   | 13%  | 获得 15~40 点经验                             |
| 独行商人   | 7%   | 15 银两购买金疮药（银两不足时商人会摇头离去） |
| 偶遇陆小凤 | 3%   | 触发剧情场景                                  |
| 风平浪静   | 2%   | 什么也没发生                                  |

## 物品系统

### 杂货铺商品

进入杂货铺后点击"浏览商品"打开商店弹窗，使用 +/- 按钮选择购买数量。

| 商品     | 价格     | 效果              | 限购次数 |
| -------- | -------- | ----------------- | -------- |
| 金疮药   | 20 银两  | 恢复 40 点气血    | 不限     |
| 清水     | 15 银两  | 恢复 20 点内力    | 不限     |
| 大还丹   | 60 银两  | 恢复 80 点气血    | 不限     |
| 内力丹   | 40 银两  | 恢复 50 点内力    | 不限     |
| 雪莲     | 120 银两 | 恢复 200 点气血   | 5 次     |
| 铁布衫   | 60 银两  | 永久 +3 防御      | 1 次     |
| 攻击秘籍 | 180 银两 | 永久 +2 攻击      | 3 次     |
| 内力心法 | 150 银两 | 永久 +20 最大内力 | 3 次     |
| 强身健体 | 150 银两 | 永久 +30 最大气血 | 3 次     |
| 轻身步法 | 100 银两 | 永久 +3% 闪避     | 3 次     |
| 暴击秘籍 | 120 银两 | 永久 +3% 暴击     | 3 次     |

### 使用方式

- **战斗中**：点击"使用物品"按钮，在物品列表中使用 +/- 选择数量后点击"使用"
- **非战斗中**：点击右上角"物品栏"打开背包，多数量物品支持 +/- 选择后使用
- 批量使用时恢复量按 `单份效果 × 数量` 计算，且不会超过上限

## 音频控制

### 音效

- 点击"🔊 开/关"按钮控制游戏音效（战斗、受伤、获得等）
- 音量滑块同时控制音效和 BGM 音量

### 背景音乐

- 点击"🎵 开/关"按钮播放/暂停 BGM
- 点击"📁 选曲"选择本地 MP3 文件作为自定义 BGM
- 未选曲时 BGM 不会自动播放

## 存档说明

- 游戏使用浏览器 `localStorage` 自动保存
- 点击右上角 **☰ 菜单 → 存档** 手动保存
- 点击右上角 **☰ 菜单 → 读档** 读取存档
- 点击右上角 **☰ 菜单 → 新游戏** 清除存档重新开始
- 清除浏览器数据会丢失存档，旧存档加载时会自动补充缺失字段
